# לומדה: AAT, הנדסת חלבונים ודלקת

לומדה אינטראקטיבית בעברית לתלמידי י"ב במגמת ביוטכנולוגיה. היא מלמדת את הרקע העיוני לפרויקט הגמר על AAT, ובמרכזה מערכת החיסון והדלקת.

## איך פותחים

פותחים את `index.html` בכל דפדפן. אין צורך בשרת או בהתקנה. ההתקדמות נשמרת בדפדפן של התלמיד.

## מבנה

- `index.html`: הלומדה כולה, בקובץ אחד.
  - בלוק התוכן בראש הקובץ (`GLOSSARY` ו-`UNITS`) מכיל את כל הטקסטים, השאלות והמשוב, ואפשר לערוך אותו בלי לגעת בקוד.
- `SPEC.md`: האפיון המקורי של הלומדה.
